# Quantitative Trading Ecosystem

Project 1 is the simulated exchange. Later projects can use that exchange for autonomous market makers, quantitative trading agents, execution algorithms, and AI-driven strategy research.

Implementation has not started. This repository is the Project 1 knowledge base and a folder skeleton. It does not run a market.

- [Research](Research/README.md) documents the exchange: purpose, architecture, rulebook, study notes, milestones, data, and references. [Possible improvements](Research/possible-improvements.md) lists later work that is not a v1 rule.
- [Config](Config/README.md) holds project-level settings. The engine does not read them yet.
- [Market](Market/README.md) is the proposed code layout. The modules are stubs and do not implement the exchange.
